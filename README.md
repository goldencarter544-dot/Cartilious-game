# Carter's Platform Game

## Goal

This project is my starting point for building my own platform game.

I used an existing GitHub platformer as the base so I could move faster, learn from real code, and then turn it into something original.

The big goal is to revamp this starter game until it feels like my game, not just a copied demo.

## What I Want This Game To Become

- A fun platform game that works well in the browser
- A game I can keep improving over time instead of rebuilding from scratch
- A game with my own characters, world, sounds, enemies, collectibles, and goals
- A project that helps me learn coding while also making something real

## Main Revamp Goals

### 1. New Character

I want to replace the starter character with my own main character.

That includes:
- New look
- New personality
- Possibly new abilities or movement

### 2. New Scene And World

I want the game world to feel original.

That includes:
- New background art
- New level theme
- New platforms and environment pieces
- A stronger visual identity

### 3. New Sounds

I want the game to sound like its own world.

That includes:
- Jump sounds
- Coin or collectible sounds
- Enemy sounds
- Win sounds
- Background music

### 4. New Coins Or Collectibles

I want to decide what the player collects and why it matters.

That could include:
- Coins
- Gems
- Stars
- Crystals
- Theme-based items that match the world

### 5. New Mobs Or Enemies

I want enemies that fit the theme of the game.

That includes:
- New enemy designs
- New enemy behavior
- Different challenge types

### 6. New Goals

I want the end of each level to feel meaningful.

That could be:
- Reaching a flag
- Entering a portal
- Finding treasure
- Saving a character
- Beating a boss

## Learning Goal

I am new to coding, so this project is also a learning project.

That means I want the code changes and systems to be explained in a clear and simple way while I build.

## Current Starting Point

Right now this project is based on a Phaser + TypeScript platformer starter from GitHub.

It is working as the foundation, and the next job is to reshape it step by step into my own game.
